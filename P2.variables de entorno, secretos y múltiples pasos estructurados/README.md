Ejercicio 2: Pipeline con Entornos, Variables y Secretos
En lugar de un simple saludo, vas a simular un paso previo a un despliegue donde el pipeline debe validar en qué entorno se está ejecutando (por ejemplo, Desarrollo vs Producción) y utilizar una credencial simulada guardada de forma segura.

Objetivos del ejercicio:
Aprender a definir variables de entorno (env) a nivel global y a nivel de paso.

Usar GitHub Secrets para manejar información sensible de forma segura sin hardcodearla en el código.

Crear un pipeline con múltiples pasos encadenados.
